# Musical Chairs

Dance while the music plays. When it stops, chairs drop from the ceiling: grab one! There is always one chair too few,
and whoever is left standing is out. Last one sitting wins. Bump (Space, or the Bump button) to knock a rival away from a
chair. Up to 10 players; bots fill the table to 8.

Play it at https://onceworlds.com/play/musical-chairs

Plain ES modules and Canvas 2D, no build. `npm test` runs the rules, movement and whole-match tests.
